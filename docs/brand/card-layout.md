# 結果カードのレイアウト（確定分の記録）

レイアウトは確定・実装済み。**現行値の正典は `app/js/presentation/card-layout.js`**で、
この文書には確定理由と旧案からの変更経緯を残す。`scripts/brand/` 以下は検討用モックであり、正典ではない。

## 寸法の決め方

- カード寸法は**1080×1800**で、ココロパレアと同値
- 文字サイズと座標は `card-layout.js` に一元化し、描画側へ直書きしない
- 係数の出発点はココロパレアの実装値。実物比較後の調整値を現行値とする

高さの比率で縮めると内枠に食い込むため、縮めない。

|---|---|---|---|
| 注記1行目（ORVIS出典） | 130px | y=1220 | **15px**（パレアと同値） |
| 注記2行目（医学的免責） | 110px | y=1240 | 15px |
| 下部ピル | 97〜63px | y=1253〜1287、316×34 r17 | — |
| 「45問 詳細結果」 | 72px | y=1278 | 24px 明朝 |

「上位2領域」「ホランド型」との差が縮まって免責が主張しすぎるため採らなかった。

| 要素 | 縦位置 | サイズ |
|---|---|---|
| 上位2領域 | ベースライン y=875 | 30px |

  **60pxの余白**を取り、レーダーと分ける
- 当時はMVP中100pxを空白にする案だった。現行は連携済みの場合に因子バッジを置く

## 確定：カード寸法の変更（2026-09-05）

**1080×1350 → 1080×1800。**ココロパレアと同値。従来の1350は実装時に置いた値で、要件にも設計にも
根拠の記載がなかった。「4:5はSNSで切られにくい」という説明は作業中に後付けしたもので、**検証していない**。

この変更で前提が消えた確定事項は**称号の比率90%**だけだった（根拠が「縦が75%なので占有率が1.33倍」）。
ヘッダーは上端から、下部は下端からの距離で置いていたため、そのまま生きた。

## 確定：中央の領域（2026-09-05）

中央領域は y=360〜1385 の **1025px**。

| 要素 | 値 |
|---|---|
| キャラクターの上の空き | **44px**（旧位置から16px上） |
| キャラクター | **380px**。透明余白を切り落としてから配置する |
| キャラクター帯とレーダーの間 | キャラクター箱の下端からレーダーラベル帯の上端まで36px |
| レーダー | **r=240**、旧位置から47px上（下部要素32px＋レーダーだけ15px） |
| レーダー下端と「上位2領域」の間 | 位置調整後も文字被りなし |
| 小物 | **210px の絶対値**。キャラクターとの比率連動はしない。**右へ+60px** |
| キャラクターの枠取り | **なし** |

小物を絶対値にしたのは、キャラクターの大きさを変えても小物の見え方を変えたくないため。

### 称号まわり・結論の塊（2026-09-05 更新）

| 要素 | 値 |
|---|---|
| 称号 | 52px 明朝。上限幅890pxで自動縮小（実データでは発動しない） |
| 中立副題 | **29px**（26pxから変更） |
| 上位2領域の行 | 30px **太字** |
| ホランド型の行 | 26px、通常 |

「探究」という語がレーダーのラベルと下の行で重複する問題に対し、**太字を下の行だけに寄せた**。
レーダーは8領域を平等に見せ、結論は下の行が担う分担にする。

### ヘッダーのマーク（2026-09-05 確定）

**カードのマークは判定に連動して点灯する。**上位2領域の位置を点灯させる。
アプリアイコン（ホーム画面・favicon）は固定で11時・12時。

実装では、レーダーで強調する領域とマークの点灯位置を**同じ配列から導く**こと。
別々に指定すると片方だけ直し忘れる。

**点灯色は赤みの強い側を1位に置く**（1位 `#DF7F68`、2位 `#F0B06C`）。R−G が 96 対 64。
R成分そのものは `#F0B06C` のほうが大きい（240 対 223）が、見た目に赤いのは `#DF7F68`。

### アセットの透明余白について

配布用画像は1024px四方だが、実体の矩形はポーズごとに異なる。
連携時の猫・むっくん・小物は manifest の body 矩形で左右端と接地線を計算する。
8ポーズすべてで、実体の比率とカード内への収まりを確認済み。

### 縁取り（2026-09-05 方針のみ記録）

- **小物にのみ適用する。**むっくん本体には付けない
- **白のみ。**地色 `#f4f6fa` は白に近い（コントラスト比1.08）ため、白い縁は輪郭ではなく
  **キャラクターと小物の間に隙間を作る役割**になる
- **細く、柔らかく。**具体値は実装時に実物で決める。モックの値をそのまま使わない
- 決めごとC-2を改訂済み（要件定義書 v1.14）。縁の色数と色は実装の裁量

## 確定：ヘッダーの塊の位置と称号のサイズ（2026-09-05）

**`HEADER_DROP = -11.9`。**マークの上端が y=50 になり、**ココロパレアの
`share-card-renderer.js` と同値**になる。アプリ名のベースライン100も一致する。
副題以下は0.5〜2pxずれる（こちらの要素間の間隔がもともと少し違うため）。
`card-layout.js` の `HEADER_DROP` 1か所で動かしており、個々のyは書き換えていない。
**次に動かすときもここだけを触ること。**

経緯：いったん +18 で組み、実物を見ながら 8 → −11.9 と詰めた。

**称号は 52px（最小38px）へ戻した。**~~比率90%（47px）~~ は**【失効】**。
根拠が「カードの高さが1350でパレアの75%しかないため縦の占有率が1.33倍になる」
というものであり、カードを1080×1800（パレアと同値）に変えた時点で前提が消えていた。
長さが理由ではない——最長15字でも52pxで780px、上限890pxに110px余る。

## 確定：カードの書体（2026-09-05）

ココロパレアの `share-card-renderer.js` に合わせる。

| 用途 | スタック |
|---|---|
| ゴシック | `"Noto Sans JP", "Yu Gothic", sans-serif` |
| 明朝 | `"Sigotosocket Mincho", "Noto Serif JP", "Yu Mincho", serif` |

明朝の**先頭は同梱のサブセット**を残す。ココロパレアはフォントを同梱していないため、
明朝を持たないAndroidではゴシックに落ちる。そこは本アプリ側の改善点として維持する。

## 確定：連携前後の構図と下部帯（2026-09-06・D-25）

- むっくんと小物は連携前後で同じ画像サイズ（380px／210px）を使う
- 猫の実体高はむっくん実体高の75%、実体間隔2px、猫の接地線はむっくんより50px上
- 連携済みの「猫＋むっくん＋小物」は実体全体を組んだ後、カード中央から右へ34px
- 結果画面の左右移動は固定34pxではなく、カード幅に対する比率 `34 / 1080` で適用する
- キャラクターは16px上、上位2領域・ホランド型・連携帯は32px上、レーダーはさらに15px上
- 「ココロパレアの結果」は30px・太字・濃紺で「上位2領域」とトーンを揃える
- バッジ文字は28px・高さ60px・左右余白30px・バッジ間18px
- 未連携も同じ見出しを出し、「未連携」を同じ形式のピルへ収める
