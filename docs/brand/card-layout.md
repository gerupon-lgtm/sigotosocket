# 結果カードのレイアウト（確定分の記録）

**進め方：上から順に確定させる。**確定した帯はこの文書に書き、以降は動かさない。
未確定の領域は残り高さだけを記録する。数値は `scripts/brand/build-card-header.mjs` が正典で、
確定しきったら `app/js/presentation/card-layout.js` へ移す。

## 寸法の決め方

- **文字サイズ＝幅1080に対する係数 × 要素ごとの比率。**pxを直書きしない
- **縦位置＝高さ1350に対する配分。**
- 係数の出発点はココロパレアの実装値（1080×1800）を1080で割ったもの。
  幅が同じなので横方向はそのまま使えるが、**高さは75%しかないため縦の占有率が1.33倍になる**。
  そのぶんは要素ごとの比率で調整する。

## 確定：中央の領域（2026-09-05）

カード寸法を **1080×1800**（ココロパレアと同値）に変更したため、中央領域は y=360〜1385 の **1025px**。

| 要素 | 値 |
|---|---|
| キャラクターの上の空き | 75px |
| キャラクター | 420px（カード高の23%）。**透明余白を切り落として**から配置する |
| キャラクターとレーダーの間 | 82px |
| レーダー | **r=205**、下端をMID下端から30px下げた位置に置く（縦478px） |
| レーダー下端と「上位2領域」の間 | 30px |
| 小物 | キャラクターの **50%**（210px）、**右へ+60px** ずらす |

### アセットの透明余白について

`character-pose-analysis.png` は1254px四方で、上に140px・下に147pxの透明余白がある。
そのまま配置すると420px指定でも上下それぞれ47pxが空く。**描画時に余白を切り落とす。**

ただし副作用がある。ポーズ8種は余白の量が異なる可能性が高く、切り落とすと**すべて同じ高さに正規化される**。
「立つ」と「丸まる」で本来あるはずの大小差が消える。**8種を並べて確認していないため未検証。**

### 縁取り（2026-09-05 方針のみ記録）

- **小物にのみ適用する。**むっくん本体には付けない
- **白のみ。**地色 `#f4f6fa` は白（`#ffffff` とのコントラスト比1.08）に近いため、白い縁は輪郭としてではなく
  **キャラクターと小物の間に隙間を作る役割**になる。実測でこれが最も重なりを読みやすくした
- **細く、柔らかく。**モックの太さ7px・ぼかしなしはエッジが硬い。具体値は実装時に実物で決める
- モックの縁取りは近似であり、実装（`drawSilhouette`）とは見え方が異なる。**モックの値をそのまま使わない**

実装時の注意：ぼかしを canvas で出すなら `ctx.filter = "blur(Npx)"` より
`shadowColor` + `shadowBlur` を重ねるほうが対応環境が広い。`ctx.filter` はブラウザによって扱いが異なる。
