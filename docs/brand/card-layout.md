# 結果カードのレイアウト（確定分の記録）

**進め方：上から順に確定させる。**確定した帯はこの文書に書き、以降は動かさない。
未確定の領域は残り高さだけを記録する。数値は `scripts/brand/build-card-header.mjs` が正典で、
確定しきったら `app/js/presentation/card-layout.js` へ移す。

## 寸法の決め方

- **文字サイズ＝幅1080に対する係数 × 要素ごとの比率。**pxを直書きしない
- **縦位置＝高さ1350に対する配分。**
- 係数の出発点はココロパレアの実装値（1080×1800）を1080で割ったもの。
  幅が同じなので横方向はそのまま使えるが、**高さは75%しかないため縦の占有率が1.33倍になる**。
  そのぶんは要素ごとの比率で調整する。

## 確定：下部ブロック（2026-09-04）

ココロパレア（1080×1800）の**下端からの距離をそのまま**使う。下端に固定される要素なので、
高さの比率で縮めると内枠に食い込むため、縮めない。

| 要素 | 下端からの距離 | 縦位置 | サイズ |
|---|---|---|---|
| 注記1行目（ORVIS出典） | 130px | y=1220 | **15px**（パレアと同値） |
| 注記2行目（医学的免責） | 110px | y=1240 | 15px |
| 下部ピル | 97〜63px | y=1253〜1287、316×34 r17 | — |
| 「45問 詳細結果」 | 72px | y=1278 | 24px 明朝 |
| 版数 | 44px | y=1306 | 13px、不透明度0.72 |
| 内枠の下端 | 28px | y=1322 | — |

注記は読ませるものではなく、あることが分かればよい。18px案は下部が重くなり、上の
「上位2領域」「ホランド型」との差が縮まって免責が主張しすぎるため採らなかった。

## 確定：帯・結論の塊（2026-09-04）

| 要素 | 縦位置 | サイズ |
|---|---|---|
| 上位2領域 | ベースライン y=875 | 30px |
| ホランド型 | ベースライン y=917 | 26px。文言「ホランド型：〈型名（英名）〉」 |
| 第2フェーズの帯 | y=1089〜1189、800×100 | MVPでは何も描かない |

- **上位2領域とホランド型は1つの塊として扱う（間隔42px）。**ホランド型は1位の領域を別の語彙で
  言い換えたものであり、対等な情報ではない。離すと読む人が一度立ち止まる。代わりに塊の上に
  **60pxの余白**を取り、レーダーと分ける
- 帯はMVP中100pxの空白になるが、**連携をすぐ行う予定**のため予告等は置かない
