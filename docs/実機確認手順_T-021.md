# 実機確認の手順（T-021）

**これは人がやるしかない分。**ブラウザの画面幅を変えた確認（375×812 / 1280×900）は
2026-09-05 に済んでいる。ここに残っているのは**エミュレータでは分からないこと**だけに絞ってある。

対象端末：**Pixel 6a（Android / Chrome）** と PC。

## 0. 準備

まだなら先に：**Settings → Pages → Source を「GitHub Actions」へ**。
これを入れないと deploy ジョブが `Get Pages site failed` で落ちる（2026-09-05 の実行がそうだった）。
入れたあと Actions から `Deploy to GitHub Pages` を再実行する。

Pages が出るまでは、同じ端末で見るならPCで `npm run dev` を動かし、
スマホから `http://<PCのLAN内IP>:4173/` を開く手もある（同じWi-Fiに繋ぐこと）。

確認の前に**サイトデータを消す**。初回訪問の状態から始めないと「続きから」の分岐を見られない。
Chrome → 設定 → サイトの設定 → 保存されているデータ → 該当サイト → 削除。

## 1. Pixel 6a（Chrome）

### 1-1. 称号が明朝で出るか ← **今回いちばん見たいところ**

要件（§11）が同梱フォントを入れた理由が **「Androidの一部端末で明朝が入っておらずゴシックに落ちる」**
だったので、Androidの実機で確かめるのが本題になる。

- [ ] 結果画面の**称号**が明朝（筆の入り・止め・はねがある書体）で出ている
- [ ] カード画像の**称号**も同じく明朝
- [ ] カードの「あなたの称号」「45問 詳細結果」の2つのピルも明朝
- [ ] **豆腐（□）が1文字も無い**

ゴシックに見えたら同梱フォントが効いていない。Chrome の `chrome://net-export` まで行かずとも、
PCからUSBデバッグでリモートデバッグし、DevTools の Network で
`sigotosocket-mincho.woff2` が 200 で返っているかを見るのが早い。

### 1-2. 共有（S-004）— **エミュレータで確認できない最大の項目**

- [ ] 「共有」を押すと**Androidの共有シートが開く**
- [ ] 共有先（例：自分宛のGmail下書き、Keep、Files）に**カード画像そのもの**が渡る
      （URLだけになっていないか。`navigator.canShare({files})` が false だとURL共有へ落ちる）
- [ ] 共有をキャンセルしてもアプリが壊れない。結果画面へ戻れる
- [ ] 「画像を保存」で **1080×1800 のPNG**がダウンロードに入る
- [ ] 保存した画像をギャラリーで開き、**文字が切れていない・重なっていない**

### 1-3. 縦横と回転

- [ ] 縦持ちで S-001 → S-002 → S-003 → S-004 を通しで完走できる
- [ ] **横スクロールが出ない**（左右に振ってもページが動かない）
- [ ] 横持ちに回転しても設問文と選択肢が読める
- [ ] 文字サイズを大きく（設定 → ディスプレイ → フォントサイズを最大）しても
      選択肢が重ならず、押せる

### 1-4. 中断と復帰

- [ ] 10問ほど答えてタブを閉じ、開き直すと**同じ問・同じ回答から**続く
- [ ] トップに「続きから（n / 45問）」が出る
- [ ] シークレットタブで開いて回答 → 保存できない旨の通知が出るか、
      少なくとも**回答を続けられて結果まで到達できる**

### 1-5. 判定不能の経路

- [ ] 45問すべて「どちらでもない」で答える
- [ ] 「称号を決められませんでした」が出て、**レーダーは出る**
- [ ] カードへ進める。カードに**正面を向いて座ったむっくん**が描かれている
      （点線の枠と「キャラクター画像は準備中です」が出ていたら不具合。報告すること）
- [ ] ホランド型の節が**出ていない**

## 4. 見つけたら報告してほしいこと

| 症状 | たぶんの原因 |
|---|---|
| 称号がゴシック | 同梱フォントが読めていない。CSPかMIMEかパス |
| 豆腐（□）が出る | サブセットに無い字。`npm run fonts:subset` の実行漏れ |
| カードに点線の空枠 | アセットの読み込み失敗 |
| 共有で画像が渡らずURLだけ | `canShare({files})` が false。端末・ブラウザ側の制約かもしれない |
| 横スクロールする | どこかの要素が画面幅を超えている。**どの画面か**を控える |

**このチェックが全部通ったら T-021 を完了にできる。**通らなかった項目は
`docs/tasks.md` の T-021 に症状と端末を書き残すこと。
