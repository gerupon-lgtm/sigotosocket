### 2-3. ②整合／不整合の要点（いちばん新しい設計・D-22）

**並置型で出す。**「特性からはこう予想されるが実際は違った」とは書かない。
本人の2つの事実と、原典で報告された結びつきの強さを**別々に**書き、
両者を結ぶ推論は読み手に返す。

これは `processing-design.md` §10-2 の検証ゲートを
**「②を出すか出さないか」から「言い切りの強さ」へ変えた**ことと対になっている。
友人サンプル（n=10〜20）が揃わなくても②を出せるようにし、
**符号が再現したら残差型へ格上げしてよい**という形にしてある。

**節の前書きの後半2文が、そのゲートの置き換えそのもの。削らないこと。**

> ただしその数値は英語の原版のもので、日本語にした45問で同じ強さが出るかは、まだ確かめていません。
> 読み方が当てはまるかどうかは、あなたが決めてください。

判定の骨子（詳細は `processing-design.md` §8-2）：

- 対象は6ペアのみ。**増やさない**（決めごとB-2）
- いずれかの `|z|` が 0.3 未満のペアは落とす
- 強さは向きで測り方が違う。揃った＝`min(|z|)`／分かれた＝`|gap|`
- 同じ因子・同じ尺度は1回まで。最大2件。0件でも1件出す（決めごとB-3）

## 5. 落とし穴（実際に踏んだもの）

**同じ穴を掘り返さないための記録。**

### CSPが style 属性を無視する
`app/index.html` の CSP は `style-src 'self'`。**`setAttribute("style", ...)` はブラウザに黙って無視される。**
エラーも出ない。テスト用のDOMスタブでは通るので、単体テストでも気づけない。
インラインの寸法は **`element.style.width = ...`（CSSOM）で入れること。**
`character-figure.js` がこの形で、`character-figure.test.js` が
「style属性を使っていないこと」をテストで縛っている。

### `hidden` は `display` を持つ要素には効かない
`[hidden]` の UA スタイルは `display:none` だが、`.character-fallback { display:flex }` の方が詳細度が高い。
`.character-fallback[hidden] { display: none; }` を別途書く必要がある。

### 開いたままのタブは、保存を更新しても画面が古い
`hashchange` は `receiveBigFive()` で **localStorage を更新する**が、
`main.js` のメモリ上の `snapshot` は自動では入れ替わらない。読み直す一行が要る（T-038）。
**起動時の経路（`main.js` 冒頭）は受け取りのあとに読み込むので問題にならない。**別経路であることに注意。

### ヘッドレスChromeの最小ウィンドウ幅は500px
`--window-size=390` を渡しても 500px で描画され、**右側が切れた画像ができる。**
カードの確認画像は必ず 500px 以上で描画し、送る前に寸法を確かめること。

### ブラウザがモジュールを掴んだままになる
実装を直したのに動かない、という誤診を2回した。
`app/dev-server.mjs` は `cache-control: no-store` を返すようにしてあり、テストで固定してある。
それでも**ハッシュだけを変える遷移ではページは再読み込みされない**（`location.reload()` が要る）。

### `git checkout -- <file>` で未コミットの実装を消した
バッジの描画を丸ごと失って書き直した。**部分的に戻したいときは使わないこと。**

### sharp の処理順序
`extract → resize → extend` の順で適用される。`extend` で正方形化しようとすると
**リサイズ後**に効いて寸法が狂う。`fit: "contain"` で一度に行う。

### キャラクターアセットの余白
1枚ずつ余白を切ってはいけない。ポーズの縦横比は 0.75〜1.05 とばらついていて、
1枚ずつ切ると立ち姿と伏せ姿が同じ高さに正規化される。
`npm run character:build` は**全種の実体を包む共通矩形**で切る。

### モックと実装は別物
`scripts/brand/build-card-full.mjs` は検討用のモックで、SVG＋sharpで描いている。
実装はcanvas。**特に縁取りはモックの見え方と実装が異なる。**モックの数値をそのまま使わない。
カードの実物を見るときは `app/__mock/real.html`（実装のレンダラーを呼ぶ）を使う。

### 文字被りのテストには穴が空きやすい
`card-layout.test.js` の「重なって当然の組」は**ピルとその中の文字だけ**。
一度「称号ピル|称号」を許可してしまい、称号を60px動かしても検出できない状態になっていた。
**許可リストを増やすときは、座標をずらす変異テストで実際に落ちることを確認すること。**

### 決定ログは追記専用
一度、文字列置換で D-01 の本文を書き換えて履歴を壊した。
古い決定は**本文を残したまま `【失効】` の印を付す**。

### 幅の見積もり
和文は原則全角なので「文字数 × フォントサイズ」を上限として使える。
ラテン文字・数字は半角。実行環境の書体差を吸収する安全側の見積もり。

npm run sample:check <回答CSV>     # 尺度別αと6ペアの符号を出す

`fonts:subset` と `character:manifest` は `node_modules` が要る。生成物はgit管理しているので、
**普段は実行しなくてよい。**称号やアセットを変えたときだけ実行する。実行し忘れはテストが落として知らせる。

**CIは `npm ci` を実行しない。**node_modules 無しで `npm test` を走らせるので、
**テストから依存パッケージを読まないこと。**これを破ると CI だけが落ちる。

配信するのは `app/` そのままではなく、**`__mock` / `tests` / `dev-server.mjs` を
落とした `dist/`**。除外はテストで固定してある。
