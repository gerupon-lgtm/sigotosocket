# ブランド — シゴトソケット

## 1. マーク

**8つの差し込み口のうち、上位2領域だけが点灯する。** 8つはORVISの8領域、点灯2つは判定結果の上位2つ。
ココロパレアのマークが「5枚の花びら＝ビッグファイブの5」であるのと同じ作り方で、数が5から8に変わっている。

| 項目 | 値 |
|---|---|
| 地 | `#1f3a5f`、角丸四角 rx=28（viewBox 120） |
| 口 | 8個。環の半径33、口の半径11、すべて塗り |
| 未点灯 | `#f4ecdd` |
| 点灯 | 1位 `#DF7F68`（朱）、2位 `#F0B06C`（山吹）。**赤みの強い側を1位に置く**（R−G が 96 対 64） |
| 並び | 12時を0として時計回り。`SCALE_ORDER` に対応 |
| アイコンの点灯 | index 7（11時）と 0（12時） |

生成は `app/js/presentation/mark.js` の `buildMarkSvg(litIndexes)` に一本化してある。
アイコン・OGP・（将来の）カードはすべてここから作る。手で描いたSVGを別に置かない。

```
npm run brand:icons
```
で `app/assets/brand/` に mark.svg・icon-180/192/512.png・ogp.png が再生成される。

### 決めるにあたって捨てた案

| 案 | 落とした理由 |
|---|---|
| 8領域を放射状の要素で描く | 太陽・花・カメラの絞りに見える |
| 差し込み口を正面から左右対称に描く | 一時停止ボタンにしか見えない |
| 未点灯を暗い穴にする | 紺地に沈んで見えなくなる |
| 未点灯を中空の輪にする | 48px以上でしか成立せず、タブの16〜32pxで破綻する |
| 点灯した口を大きくする | 対向の組で大玉が浮いて不格好になる。対向でも弱くならないため不要 |
| ハリネズミ（むっくん）をマークにする | 造形としては成立するが、キャラクターの絵柄確定前に決められない |

**16px（ブラウザのタブ）は潰れる。これは許容する。** ココロパレアのマークも16pxでは潰れている。
形を16pxに合わせて単純化すると、必ず既製の記号に着地する。

## 3. HTMLに置くもの

`app/index.html` に canonical・webmanifest・favicon(SVG)・apple-touch-icon・OGP・CSPを持つ。
URLの正典は `appMeta.siteOrigin`。**サブドメインが未確定（検討事項21）なので現在は【仮】**で、
確定したら `app/js/config/app-meta.js` の1箇所を直せば `npm run check` と
`app/tests/brand-assets.test.js` が index.html との食い違いを検出する。

公開文言は2026-09-04に確定（要確認24を解消）。

| 場所 | 文言 |
|---|---|
| タイトル・og:title | シゴトソケット｜ORVIS 職業興味の自己理解支援ツール |
| description・og:description | ORVIS短縮版45問で、8つの領域から興味のかたちを見ます。結果はこの端末にのみ保存されます。 |
| OGP画像のコピー | やってみたいことのかたちを見る |
| カードのサブタイトル | 〜ORVIS 自己理解支援ツール〜（2026-09-04 短縮） |

「自己理解支援ツール」はココロパレアのサブタイトル（〜Big Five 自己理解支援ツール〜）と語尾を揃えたもの。
カードのサブタイトルは当初「〜ORVIS 職業興味の自己理解支援ツール〜」だったが、ヘッダーのロックアップ
（アイコン＋アプリ名＋副題を同じ幅の塊にする作り）に収まらず472pxとなったため、**「職業興味の」を外して322pxに短縮**した。
パレアの副題が356pxで上限360pxにちょうど収まる設計だったことが判明したための調整。職業興味という語は
タイトルタグとOGPの説明文に残っているため、検索・共有の場面では失われない。
コピーはORVISが測るもの（どんな活動をやってみたいか）をそのまま言っている。マークの比喩を文へ持ち込む案
（「8つのうち、あなたに灯る2つ」など）は、興味について人が使う言葉ではないため採らなかった。
