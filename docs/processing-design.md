# 処理設計 — シゴトソケット

判定はすべてルールベース。**LLMに判断させない。**

## 1. 採点（F-003）

```
raw[s] = mean( answers[i] for i in items(s) )        # 1.00〜5.00
```

- 未回答が1件でもあれば結果へ進めない（F-001の入力チェック）
- 丸めは表示時のみ。内部は倍精度のまま扱う

## 2. 個人内標準化（F-003・変更禁止事項1）

```
m  = mean( raw[s] for s in 8尺度 )
sd = sqrt( mean( (raw[s] - m)^2 for s in 8尺度 ) )   # 母集団標準偏差（÷8）
z[s] = (raw[s] - m) / sd
```

- **母集団標準偏差（÷n）を使う。標本標準偏差（÷n-1）に変えない**
- `sd == 0`（全尺度が同値）のとき、z を計算せず `standardizable = false` とし、専用メッセージを表示する。**ゼロ除算を発生させない**
- 浮動小数の誤差で `sd` が極小になる場合に備え、`sd < 1e-9` を判定不能として扱う
- ビッグファイブ側も同じ式で5因子内標準化する（第2フェーズ）

## 3. 順位付け

```
rank = 8尺度を z の降順で並べたもの
```

- z が同値の場合は**正準順で安定ソート**する。実行ごとに順位が変わってはならない

## 4. タイプ判定（F-004）

```
typeId = type-<正準順で並べた rank[0], rank[1]>
```

**僅差の扱い**（変更禁止事項なし・閾値は【想定】0.15）:

```
if |z[rank[1]] - z[rank[2]]| < THRESHOLD:
    alternativeTypeId = type-<正準順で並べた rank[0], rank[2]>
```

- 2つのタイプ名を「どちらとも読めます」として並べて提示する。1つに断定しない
- rank[0] と rank[1] が僅差でも `typeId` は変わらない（順序なしのため）。**この性質のおかげで1位・2位の入れ替わりに強い**
- `standardizable == false` のときは判定せず、`primaryTypeId = null`

## 5. カードの絵柄決定（F-019）

```
pose = character-pose-<rank[0]>      # 1位尺度でポーズが決まる
prop = prop-<rank[1]>                # 2位尺度で小物が決まる
```

- タイプ名は28通り、絵柄は順序を反映して56通りの見え方になる（`docs/data-model.md` §5）
- `standardizable == false` のときは中立のポーズ（【要確認】：どのポーズを中立とするか。専用の9枚目を作るか）を使う

## 6. 結果文の組み立て（F-006）

アプリ側で**そのまま表示できる完成文**まで作る。

1. タイプ名と説明（命名表から取得）
2. 上位2尺度の解説（尺度定義から取得）
3. 下位1尺度の解説（「相対的に低い」とのみ書く。**「苦手」「向いていない」と書かない**）
4. 判定不能時は専用文

**禁止**: 「平均より高い」「人より〜」「〇〇な人は少数派」等、集団比較を含む表現（変更禁止事項2）。文言テンプレートの単体テストで、禁止語の混入を検出する。

## 7. LLM推敲（F-007・第2フェーズ）

- 入力は**組み立て済みの結果文のみ**。回答値・尺度得点・個人情報を渡さない
- プロンプト制約: 意味を変えない／新しい主張を足さない／断定を強めない／尺度名と数値を変えない
- 出力検証: 元の文に含まれる**尺度名とタイプ名がすべて残っている**ことを機械的に確認する。欠落していれば推敲結果を破棄し、元の文を使う
- タイムアウト3秒。失敗・停止・検証NGのいずれでも、F-006の出力をそのまま表示する（利用者にエラーを見せない）

## 8. 整合／不整合の判定（F-012・第2フェーズ・変更禁止事項3）

対象は次の6ペアのみ。

| Big5因子 | ORVIS尺度 | 参照相関（符号と大小のみ使用） |
|---|---|---|
| intellectImagination | creativity | .30 |
| intellectImagination | erudition | .34 |
| intellectImagination | leadership | .29 |
| agreeableness | altruism | .42 |
| extraversion | leadership | .38 |
| conscientiousness | organization | .20 |

```
gap[pair] = z_orvis[scale] - z_bigfive[factor]
```

- `|gap|` の大きい上位1〜2件のみ提示する
- **参照相関を係数として掛けない**。ペアを選ぶ根拠としてのみ使う
- 該当が閾値未満なら「あなたは特性と興味が一貫しています」を出す。**これも正式な結果**（変更禁止事項4）

## 9. 固有性の判定（F-013・第2フェーズ）

- 対象は Big5 との相関がほぼゼロの尺度（`production`・`adventure`）
- `z` が上位に入っている場合、「性格特性からは予測できない、あなた固有の興味」として提示する
- 根拠は「予測できないこと自体が事実である」点。①②より説明の確度は高い

## 10. 検証（実装前・実装後）

### 10-1. 合成プロフィールの端値テスト（必須）

| ケース | 期待 |
|---|---|
| 全項目1 | `standardizable = false`、専用メッセージ、例外を投げない |
| 全項目5 | 同上 |
| 全尺度の平均が完全一致 | 同上 |
| 1尺度だけ突出 | 1位が確定し、2位以下が僅差なら代替タイプが出る |
| 2位と3位が完全同値 | `alternativeTypeId` が設定される |
| 1位と2位が完全同値 | `typeId` が変わらない（順序なしの性質） |
| 未回答が1件 | 結果へ進めない |
| 浮動小数で sd が極小 | 判定不能として扱う |

### 10-2. 友人サンプル（n=10〜20）での符号確認

翻訳後の項目で、§8の主要な相関（agreeableness↔altruism、intellectImagination↔creativity/erudition、extraversion↔leadership）の**符号が再現するか**を確認する。値の一致は求めない。再現しない場合は②層を落とし、①③のみで提供する。

### 10-3. 短縮後のα実測

同サンプルから各尺度のCronbachのαを算出するスクリプトを用意する（`scripts/items/alpha.mjs`）。推定値（全尺度.72以上）と比較する。
