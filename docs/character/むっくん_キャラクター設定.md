# むっくん — キャラクター設定

シゴトソケットの案内役。ハリネズミ1匹。姉妹アプリ「ココロパレア」の猫と同じ思想で、**1種類のキャラクターの姿勢と小物の違い**でタイプを表し分ける。

## 1. 基本設定

| 項目 | 内容 |
|---|---|
| 名前 | **むっくん** |
| 種 | ハリネズミ（1種類・個体は常に同一） |
| 役どころ | 8つの領域それぞれの「やってみたいこと」を、道具と所作で見せる |
| 画風 | 精密な色鉛筆・図鑑風。中央に全身1体、周囲に道具を配置 |
| 画寸 | 1024×1024、**背景透過（アルファ付き）** |
| 焼き込まないもの | 背景、文字、カード色（カード側でcanvas合成する） |

## 2. 造形の固定要素（全ポーズで共通）

同一個体に見えることが最優先。次はポーズが変わっても変えない。

- 体格：小柄でずんぐり。頭・胴・四肢の比率を固定する
- 針：背中側のみ。淡い茶と生成りの縞。**先端を鋭く尖らせない**
- 顔：白〜クリームの毛、黒い丸い目、濃い鼻先。表情は穏やかで、口は閉じるか薄く開く程度
- 前足：4本指。**道具を持てる**手つきに描く（この作品での約束事）
- 服は着せない。持ち物だけで役割を示す

## 3. 描いてはいけないもの（必須ルール）

要件定義書§11-2に基づく。破ると診断結果に余計な意味が乗る。

1. **丸まって針を立てた防御姿勢を使わない。** 拒絶・警戒・閉じこもりに読まれ、「心を閉ざしている」という含意が結果に付く。むっくんは常に**開いた姿勢**（座る・歩く・前足で道具を扱う）
2. **針を「とげとげしい性格」「近寄りがたさ」の記号として使わない。** 針は造形であって性格ではない
3. **職業そのものを描かない。** ORVISの項目には「農家になる」「警察官になる」等の具体的職業が含まれるが、直訳すると職業の貴賤や序列に読まれる。**活動の質感（道具と所作）に変換する**。制服・白衣・作業着・記章を描かない
4. 体格・針の量・毛色と、領域の優劣や能力を結び付けない
5. （第2フェーズ）猫と並べるとき、**互いに視線を向けない／縮尺を揃える／覗き込まない／覆いかぶさらない**

## 4. 8つのポーズ（1位の領域で決まる）

**ポーズの絵に道具を焼き込まない。むっくん単体を、所作だけで描き分ける。** 道具はすべて小物レイヤー（§5）として別に持つ。

役割分担は「**所作＝1位の領域／小物＝2位の領域**」。1つの絵の中で同じ領域を二重に表さない。

シルエットで見分けられるよう、姿勢の大分類を散らしている。

| 領域 | ID | 所作 | シルエットの特徴 |
|---|---|---|---|
| 統率 | `character-pose-leadership` | 後ろ足で立ち上がり、前足を前方へまっすぐ伸ばす | 縦に長い。唯一の直立 |
| 段取り | `character-pose-organization` | きちんと座り、両前足を揃えて床につけ、背筋を伸ばす | 左右対称。輪郭が整う |
| 支援 | `character-pose-altruism` | 前へ身を乗り出し、両前足を画面外へ差し出す | 前傾＋前足が前へ突き出る |
| 創造 | `character-pose-creativity` | 横向きに座り、片前足を高く上げて空へ線を引く。頭を少し傾ける | 斜め。片前足だけが上 |
| 探究 | `character-pose-analysis` | 前かがみで鼻先を下へ近づけ、じっと見つめる | 頭が低く、背が丸く高い |
| 手仕事 | `character-pose-production` | しゃがんで両前足を地面につけ、掘る・こねる | 低く横に広い |
| 挑戦 | `character-pose-adventure` | 片足を大きく踏み出し、体を前傾させて走り出す直前 | 前後に長い。動きがある |
| 言葉 | `character-pose-erudition` | 座って顔を上げ、耳を立てて口を開く（語る・聞く） | 顔が上向き。耳が立つ |
| （中立） | `character-pose-neutral` | 正面を向いて座り、前足を自然に下ろす | 正面・静止 |

**中立ポーズ**は、8領域すべてが同点で称号を決められなかったときに使う。

> **注意**：座り姿勢が「段取り」「言葉」「中立」の3つで近くなる。前足の置き方（揃えて床／体側／自然）と顔の向き（手元／上向き／正面）で必ず差をつけ、**生成後に3枚を並べて見分けられるか確認する**。見分けられなければ、段取りを「片前足を前へ出して数える所作」へ振り直す。

## 5. 8つの小物（2位の領域で決まる）

ポーズとは別レイヤーで、カードの手前側に小さく配置する。単体で意味が読めるものを選ぶ。

| 領域 | ID | 小物 |
|---|---|---|
| 統率 | `prop-leadership` | 台座に立てた小さな三角旗 |
| 段取り | `prop-organization` | 重ねた番号札と砂時計 |
| 支援 | `prop-altruism` | 湯気の立つカップ |
| 創造 | `prop-creativity` | 絵の具皿と筆1本 |
| 探究 | `prop-analysis` | 虫めがね |
| 手仕事 | `prop-production` | 木槌と木片 |
| 挑戦 | `prop-adventure` | 巻いた縄 |
| 言葉 | `prop-erudition` | 積んだ本3冊 |

**職業を示す道具を使わない。** 制服・白衣・作業着・記章・警棒・聴診器のたぐいは、どの小物にも入れない。

## 5-A. サイズ感（カード上の実寸）

カードは 1080×1350。ポーズと小物は現行の `card-renderer.js` の値で、次のように置かれる。

| | 配置枠 | アセット内の占有率 | カード上の実寸 |
|---|---|---|---|
| ポーズ（むっくん） | 600×480（中央上寄り） | 約70% | **高さ 約336px** |
| 小物 | 180×180（ポーズ枠の右下） | 約60% | **約108px** |

**小物はむっくんの高さの約32%。** 目安として「3割」と覚えておけばよい。ハリネズミの実寸を体長20cm前後とすると、小物は6cm相当になる。カップ・ルーペ・木槌はちょうどよく、積んだ本や旗はやや小さめに見える。

これは**実物大の関係ではなく、カード上でむっくんを主役に見せるための比率**として決めた値。生成時の見かけの大小は問わない（カード側でリサイズする）が、正方形の枠に素直に収まる形で作ること。極端な縦長・横長にすると、リサイズ後に小さくなりすぎる。

視覚的な確認用に `docs/character/サイズ感.png` を置いてある。

> **【要確認】** 現在の配置では、小物がむっくんの右下に**重なる**。小物は後から描くので手前に来る。実アセットができたら、重なりが自然に見えるか（手元に置いた道具として読めるか）を確認し、必要なら小物の位置をポーズ枠の外側へずらす。

## 5-B. 地色に沈ませない（視認性補助）

むっくんは**クリームの顔**と**茶の針**という明暗2トーンを持つ。カードの地色によっては、どちらか一方が必ず背景へ溶ける。実際、現行の地色 `#f4f6fa` に対して**顔側のコントラストは1.11**しかない。

ココロパレアが確立した方針をそのまま踏襲する。

> **キャラクターを再配色しない。地色も差し替えない。** 代わりに視認性補助を決定的に適用する。

| 補助 | いつ出るか |
|---|---|
| 縁取り＋影 | 明側・暗側のどちらかが地色とのコントラスト比 3.0（WCAG 1.4.11）を下回るとき。**縁の色数と色は実装の裁量**（2026-09-05改訂。地色を `#f4f6fa` に固定したため、暗い地色を前提とした明暗二重は必須ではなくなった） |
| ＋ ニュートラル背景プレート | さらに**両側とも**2.5を下回るとき（キャラ全体が地色へ溶ける場合） |

縁取りが明暗2本なのは、地色が明るくても暗くてもどちらかの線が輪郭を立てるため。判定は `app/js/domain/visibility-aid.js` の純関数で、同じ入力なら常に同じ結果になる。プレビューと保存画像が食い違わない。

**代表トーンは現在【想定】値**（明 `#f2ead8` / 暗 `#6b563c`）。アセット制作後、実画像から測った値へ置き換える。

## 6. 命名と検証

- ファイル: `app/assets/characters/character-pose-<scaleId>.webp`、`app/assets/props/prop-<scaleId>.webp`
- manifest: `npm run character:manifest` で `characterId` / `assetVersion` / `imagePath` / `alt` / `integrity`(sha256) を生成
- 検証: `npm run character:check` で存在・寸法・ハッシュ一致に加え、**全アセットにアルファチャンネルがあり四隅が透明であること**を機械的に確認する（白背景のまま書き出す事故を防ぐ）
- `alt` は全件必須。「ルーペを覗き込むハリネズミ」のように、所作と道具を書く
