# むっくん — 画像生成プロンプト集

18枚（ポーズ9・小物8・ゲスト用1）の英語プロンプト。**同一個体に見えること**が最優先なので、共通ブロックは一字も変えずに毎回先頭へ置く。

## 0. 使い方

1. `BASE` ＋ `POSE`（またはオブジェクト用の `OBJECT_BASE` ＋ 各小物）を連結して1本のプロンプトにする
2. 同じシード値を使い回すと個体差が減る。ポーズ違いでシードを固定して試す
3. 生成後は白背景を透過へ抜く（`npm run character:alpha`）
4. `npm run character:check` で四隅の透明を確認する

**FLUX.1 [schnell] を使う場合の注意**：`num_steps` は 4。ネガティブプロンプトに対応しないため、**打ち消したい要素は肯定文で言い換えて `BASE` に織り込んである**（"quills with blunt rounded tips", "body uncurled and open" など）。対応するモデルを使う場合は §4 のネガティブを併用する。

## 5. 生成後の必須チェック

| 観点 | 見るところ |
|---|---|
| 同一個体か | 9枚を並べ、体格・針の縞・顔の色・目の大きさが揃っているか |
| 丸まっていないか | どの絵も体が開いているか。針が逆立っていないか |
| 針の先端 | 鋭く尖っていないか（攻撃性・近寄りがたさに読まれる） |
| 前足 | 4本指で、道具を扱えそうな手つきになっているか |
| 職業の記号 | 制服・白衣・記章のたぐいが紛れていないか |
| 見分け | **段取り・言葉・中立の3枚**が並べて区別できるか（座り姿勢が近い） |
| 背景 | 純白か（透過処理の前提）。影や地面が描き込まれていないか |

## 6. ゲスト出演用（第2フェーズ）

ココロパレアのカードに置く1図柄。猫と並べても対立に見えないよう、**正面向きで静止した中立ポーズ**を流用する想定。着手前に本人の許可を取る。
