# むっくん — 画像生成プロンプト集

18枚（ポーズ9・小物8・ゲスト用1）の英語プロンプト。**18枚が同一個体・同一シリーズに見えること**が最優先。共通ブロックは一字も変えずに毎回先頭へ置く。

## 0. 進め方

1. **まず基準画像を1枚作る。** `character-pose-neutral`（正面・静止）を何枚か生成し、むっくんの姿として納得できる1枚を選ぶ
2. その1枚を**参照画像**として、以降の8ポーズを生成する（image-to-image / reference。対応しないモデルなら**シードを固定**して振れ幅を抑える）
3. 小物8点は `OBJECT_BASE` で別に生成する
4. 白背景を透過へ抜く（`npm run character:alpha`）
5. 体裁を検査する（`npm run character:check`）
6. 実画像から代表トーンを測る（`npm run character:tones`）。視認性補助の判定に使う

**採用の目安**：1枚あたり4〜8枚生成して選ぶ。基準画像だけは20枚ほど作って選ぶ価値がある。ここが揺れると18枚すべてが揺れる。

**FLUX.1 [schnell] を使う場合**：`num_steps` は 4。ネガティブプロンプトに対応しないため、**打ち消したい要素は肯定文で言い換えて `BASE` に織り込んである**。対応するモデルでは §5 のネガティブを併用する。

## 1. 共通ブロック（BASE）

```
A single hedgehog character, colored pencil naturalist illustration, fine detailed
linework, soft even natural shading, warm muted palette,
small rounded plump body, warm sandy brown quills with pale cream banding,
quill tips blunt and rounded, pale cream face and belly fur, round black eyes,
small dark nose, short whiskers, front paws simply shaped with four short fingers,
calm gentle expression, no clothing,
body uncurled and open, full body visible with margin on all sides,
subject fills about 70 percent of the square frame,
eye level camera, square 1:1 composition, single subject centered,
flat plain pure white background, no ground, no cast shadow, no text, no border,
```

### 固定する理由

| 指定 | なぜ要るか |
|---|---|
| `warm sandy brown / pale cream` と色を言葉で固定 | 色が振れると18枚の統一感が崩れ、視認性補助の代表トーンも決まらない |
| `subject fills about 70 percent` | 各絵でむっくんの大小が変わると、カード上で並べたときにばらつく |
| `eye level camera` | ある絵は真横、ある絵は俯瞰、になるのを防ぐ |
| `no ground, no cast shadow` | 透過へ抜くので接地影は邪魔になる。影はカード側でcanvasが付ける |
| `front paws simply shaped with four short fingers` | 生成AIは手の描写を崩しやすい。細部を求めず単純な形に寄せる |

**カード上の実寸**：むっくんは高さ約336px、小物は約108px（**むっくんの約32%**）。1080×1350のカードでの値。詳細と図は設定書§5-A（`docs/character/サイズ感.png`）。

生成時の見かけの大小は問わない（カード側でリサイズする）が、**極端に横長・縦長の構図にしない**こと。正方形の枠に素直に収まる形で作らないと、リサイズ後に小さくなりすぎる。

## 4. 職業を示す道具を使わない

制服・白衣・作業着・記章・警棒・聴診器・ヘルメットのたぐいは、ポーズにも小物にも入れない。ORVISは職業興味の尺度だが、職業をそのまま描くと貴賤や序列に読まれる（設定書§3-3）。

## 6. 生成後の必須チェック

| 観点 | 見るところ |
|---|---|
| 同一個体か | 9枚を並べ、体格・針の縞・顔の色・目の大きさが揃っているか |
| 大小 | 各絵でむっくんの占める割合が揃っているか |
| 視点 | 俯瞰や煽りが混ざっていないか |
| 丸まっていないか | どの絵も体が開いているか。針が逆立っていないか |
| 針の先端 | 鋭く尖っていないか（攻撃性・近寄りがたさに読まれる） |
| 前足 | 指の数が破綻していないか。生成AIが最も崩しやすい箇所 |
| 職業の記号 | 制服・白衣・記章のたぐいが紛れていないか |
| 見分け | **段取り・言葉・中立の3枚**が並べて区別できるか（座り姿勢が近い） |
| 背景 | 純白か。接地影や地面が描き込まれていないか |

見分けがつかない場合は、段取りを「片前足を前へ出して数える所作」へ振り直す（設定書§4の注記）。

## 7. ゲスト出演用（第2フェーズ）

ココロパレアのカードに置く1図柄。猫と並べても対立に見えないよう、**正面向きで静止した中立ポーズ**を流用する想定。着手前に本人の許可を取る。
